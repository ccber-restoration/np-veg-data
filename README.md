# Overview

This repository is used for data analysis of quadrat monitoring data of North Parcel (https://ccber.ucsb.edu/restoration-area-north-parcel).

The monitoring data used in this analysist has already been filtered through and cleaned [by Francis]. 


## Data

Monitoring data are collected via the Survey123 form (https://survey123.arcgis.com/): CCBER VegMonitoring QuadratTransects

  - Temporal coverage: 2021 onward. It does not include data from before 2021. While that data does exist(and can be found in Box), due to the difference in format and limited value for management practices, it has been excluded from these analyses.
  - There are 18 quadrat transects, all of which are monitored at 2-m intervals (not 3 m). Transect locations are in the Cheadle Center Vegetation Monitoring Transects web map (https://ucsb.maps.arcgis.com/home/item.html?id=7ff7c62b277f45da9945d1f3428f491f#overview), specifically the NorthParcel_VegMonitoring_Transects_Major and NorthParcel_VegMonitoring_TransectPoints feature layers
  - Note that transect names have varied over time. See NameChange.csv for a crosswalk.
  - Note that Phelps Trail vegetation monitoring transects (PT-01, PT-02, PT-03), whic were established in summer 2026, are recorded with project site = North Parcel, but those data should be treated separately and have not been included in North Parcel monitoring reports.
