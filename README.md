# Overview

This repository is used for data analysis of quadrat monitoring data of North Parcel.

The monitoring data used in this analysist has already been filtered through and cleaned [by Francis]. 


## Data

Monitoring data are collected via the Survey123 form (https://survey123.arcgis.com/): CCBER VegMonitoring QuadratTransects (2021 onward; 
     - It does not include data from before 2021. While that data does exist(and can be found in box), due to the difference in format and limited value for management practices, it has been excluded from these analyses.
